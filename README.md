# KOFULL · Experiencia web

Web de marca de KOFULL, bebida funcional nacida del MMA en Valencia (2026). Experiencia 3D guiada por el scroll: la lata de 473 mL construida en tiempo real con la etiqueta original, 12 escenas, tienda con pasarela de pago de demostración y versión móvil propia.

**Web:** https://nocodya-hue.github.io/kofull/
**Vista previa en iPhone:** https://nocodya-hue.github.io/kofull/preview-movil.html

## Tecnología
- Three.js / WebGL (lata, luz, suelo con reflejo, agua)
- GSAP + ScrollTrigger + SplitText, Lenis (scroll suave)
- HTML, CSS y JavaScript estáticos, sin compilación

## Estructura
- `index.html` · contenido y escenas
- `css/kofull.css` · sistema visual
- `js/stage.js` · escena 3D · `js/scenes.js` · coreografía · `js/main.js` · scroll, textos, tienda
- `assets/tex` · etiquetas 2K de los cuatro sabores · `assets/img` · fotografía
- `DIRECCION.md` · dirección artística y mapa de escenas

## Notas
- La pasarela de pago es decorativa: no cobra, no envía ni guarda datos.
- Las fotos de los rounds son provisionales; su origen está en `CREDITOS-FOTOS.md`.
